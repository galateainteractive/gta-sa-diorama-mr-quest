# Upstream provenance

Diorama MR was created from the open-source GTA San Andreas VR Quest project
and is being developed as an independent derivative repository. It is not a
GitHub-generated fork, but the original project remains the upstream source and
is credited under its MIT license.

All 117 files in the downloaded `main` archive were compared by relative path
and SHA-256 with the exact-commit archive; the content difference count was
zero.

The original Google Play split APKs, game data, audio pack, signing key, build
tools and build products remain outside this source repository and are excluded
from Git.

The repository keeps an `upstream` Git remote for reference. Future upstream
changes are reviewed and integrated selectively because Diorama MR and the
immersive VR project intentionally have different interaction and rendering
goals.
