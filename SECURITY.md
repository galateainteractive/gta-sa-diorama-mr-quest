# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository:

https://github.com/galateainteractive/gta-sa-diorama-mr-quest/security/advisories/new

Include the affected commit or version, the component involved, reproduction
steps, and the expected impact. Remove credentials, signing keys, device serial
numbers, personal paths, saves, logs containing personal data, and proprietary
game content before attaching evidence.

Do not open a public issue for an unpatched vulnerability or publish exploit
details before a fix is available. Ordinary bugs without a security impact can
use the public issue tracker.

## Scope

Security reports are accepted for this repository's source code, loader,
installer, build tools, validation logic, and update flow. Rockstar Games,
Google Play, Meta Quest firmware, third-party mods, and user-supplied game or
audio files are outside this project's control; report vulnerabilities in
those products to their respective maintainers.

Only the current `main` branch is supported. Development previews may change
without compatibility guarantees.
